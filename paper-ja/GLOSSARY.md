# 用語対応表

| 日本語 | English term | 運用メモ |
|---|---|---|
| 私的互換性 | private compatibility | 初出時は英語併記 |
| 私的迂回 | private circumvention | 法令違反・不遵守の意味ではなく、追加標準を技術的にサポートすること |
| 正式な標準化制度／正式な標準化レジーム | formal standards regime | 文脈に応じ「制度」「レジーム」を使用 |
| 地域標準化連合 | regional standardization union | 数式上の `SU` は変更しない |
| 国際標準化 | international standardization | 数式上の `IS` は変更しない |
| 各国別標準 | separate national standards | 数式上の `SW` は変更しない |
| 選択的侵食 | selective erosion | 本稿の中心メカニズム |
| 厳格ブロッキング | strict blocking | deviator全員のstrict improvementが必要 |
| 継続利得 | continuation payoff | formal partition後の企業行動・Cournot競争を織り込んだ政府利得 |
| ネットワーク効果／互換性効果 | network / compatibility effect | パラメータ `v` は変更しない |
| 互換性便益 | compatibility benefit | `g_i^k` |
| 適応費用／非互換費用 | adaptation / incompatibility cost | 限界費用 `c` |
| 追加標準の採用 | additional-standard adoption | 固定費用 `F` |
| 純排除余剰 | net exclusion surplus | `\mathscr E_i` |
| 相互的不利益 | reciprocal disadvantage | `\mathscr D_i`。profit block `D` と区別 |
| 連合 | coalition | 必要に応じ英語併記 |
| 分割 | partition | formal partition `\rho` |
| ブロッキング | blocking | coalition deviationの安定性概念 |
| Cournot競争 | Cournot competition | 固有名のため英語表記を維持 |
| 内点 | interior | quantity / consumer participationのinteriority |
| 凹性 | concavity | sign proofで用いる |
| 端点評価 | endpoint evaluation | concavityと組み合わせた符号証明 |
| 生産物市場利益ブロック | product-market profit block | `P,A,B,C,D,H,S` |
| 大連合 | grand coalition | 3国すべてからなるcoalition |
| パートナー順位 | partner ranking | coalition stabilityとは区別 |
